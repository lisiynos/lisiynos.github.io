Автоматическая генерация документации

Автоматическая генерация документации - получение справочной документации по программе прямо из её исходного текста. Генератор документации разбирает исходный код, находит объявления классов, функций, переменных и специальные комментарии к ним - документирующие комментарии - и строит по ним документ, обычно набор связанных HTML-страниц: описание каждого класса и функции, их параметры, перекрёстные ссылки, алфавитный указатель.

Документирующий комментарий обычно ставится непосредственно перед описываемым объявлением и отличается от обычного комментария формой: многие генераторы распознают комментарии вида /** ... */. Комментарий содержит описание и теги: @param описывает параметр, @return - возвращаемое значение, @throws - исключение, которое может выбросить функция. Сигнатуры функций и иерархию классов генератор берёт из самого кода, поэтому эта часть документации всегда соответствует программе. В примере ниже документирующий комментарий стоит перед функцией gcd.

Достоинства подхода: документация хранится рядом с кодом и правится вместе с ним, а собрать её можно автоматически при каждой сборке программы. Недостатки: так в основном получается справочник по интерфейсам (API); обзорные страницы и руководство пользователя приходится писать отдельно, хотя генераторы могут включать и их в собранный документ; некоторые генераторы предупреждают о неописанных параметрах, но не проверяют, что текст описания по-прежнему верен, и комментарий, который забыли поправить вместе с кодом, делает документацию неверной.

Реализация на C++

#include <iostream>
#include <stdexcept>

/**
 * Вычисляет наибольший общий делитель двух чисел алгоритмом Евклида.
 *
 * @param a первое число, не меньше нуля
 * @param b второе число, не меньше нуля
 * @return наибольший общий делитель a и b; gcd(0, 0) равен 0
 * @throws std::invalid_argument если a или b отрицательно
 */
long long gcd(long long a, long long b) {
    if (a < 0 || b < 0) {
        throw std::invalid_argument("gcd: аргументы должны быть неотрицательными");
    }
    while (b != 0) {
        long long remainder = a % b;
        a = b;
        b = remainder;
    }
    return a;
}

int main() {
    std::cout << "gcd(12, 18) = " << gcd(12, 18) << "\n";
    std::cout << "gcd(17, 5) = " << gcd(17, 5) << "\n";
    std::cout << "gcd(0, 7) = " << gcd(0, 7) << "\n";
    try {
        gcd(-4, 6);
    } catch (const std::invalid_argument& error) {
        std::cout << "ошибка: " << error.what() << "\n";
    }
}

Указатели и работа с динамической памятью

Переменные из раздела var статические: память под них отводится на всё время работы программы (глобальные переменные) или подпрограммы (локальные), и её размер известен уже при компиляции. Динамические переменные создаются и уничтожаются во время работы программы в отдельной области — динамической памяти (куче). Имени у динамической переменной нет: к ней обращаются через указатель, то есть переменную, которая хранит её адрес.

Основные средства работы с указателями в Pascal:

  • type PInt = ^Integer; — ссылочный тип: указатель на переменную типа Integer;
  • New(p) — создать динамическую переменную и записать её адрес в p;
  • p^ — сама переменная, на которую указывает p;
  • Dispose(p) — освободить память, занятую этой переменной;
  • nil — пустой указатель, который никуда не указывает.

Присваивание q := p копирует адрес, а не саму переменную: после него p и q указывают на одно и то же место. Каждую динамическую переменную нужно освободить процедурой Dispose, когда она больше не нужна. Если потерять все указатели на неё, освободить её уже нельзя — это утечка памяти. После Dispose обращаться к переменной через оставшиеся указатели нельзя: эта память ей больше не принадлежит.

Реализация на Pascal

{ Динамическая переменная: создание, обращение, удаление }
type
  PInt = ^Integer; { Ссылочный тип: указатель на переменную типа Integer }

var
  p, q : PInt;

begin
  p := nil; { Пустой указатель - никуда не указывает }
  Writeln(p = nil); { Выводит "TRUE" }
  New(p); { Создаём динамическую переменную, p хранит её адрес }
  p^ := 5; { Обращение к динамической переменной через указатель }
  q := p; { Копируется адрес: q указывает на ту же переменную }
  q^ := q^ + 1;
  Writeln(p^); { Выводит "6" - изменение через q видно и через p }
  Dispose(p); { Освобождаем память; p и q больше нельзя разыменовывать }
  p := nil;
  q := nil;
  Writeln(p = nil); { Выводит "TRUE" }
end.

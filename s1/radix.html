Системы счисления делятся на:

  • позиционные - одна и та же цифра имеет разное значение в зависимости от позиции $143=1 \cdot 10^2 + 4 \cdot 10 + 3$.
  • непозиционные - число задаётся несколькими знаками с различным значением.
  • смешанные - например, римская система счисления $IX = 9$ - значение зависит от позиции цифр, но есть ограничения.

Системы счисления

Позиционные и непозиционные

Позиционные - значение зависит от позиции цифры.

Например, десятичная система счисления: $343=3*10^2+4*10^1+3$

Перевод из одной системы счисления в другую

Мы считаем в десятичной системе счисления.

Перевод из десятичной в двоичную - деление в столбик или сравнение по таблице степеней двойки.

Перевод обратно, из двоичной в десятичную - умножение разрядов на степени двойки и сложение.

Непозиционная: Римская система счисления

I - 1, V - 5, X - 10, D - 50, L - 500, M - 1000 - значение не зависит от позиции (зависит по-другому).

Двоичная система счисления (запись чисел)

Позиционная система счисления с основанием 2, Числа записываются с помощью двух символов: 0 и 1.

Например: число $3 = 11_2$.

$\ x_{2,2} = a_{n-1} a_{n-2}\dots a_{1} a_{0\ 2,2} = \sum_{k=0}^{n-1} a_k b^k = \sum_{k=0}^{n-1} a_k 2^k,$
где:

  • $\ x_{2,2}$ — представляемое число, первый индекс - основание системы счисления (размерность множества цифр $a={0,1}$), второй индекс - основание весовой показательной функции $b$ (в двоично-десятичном кодировании $b=10$),
  • $\ a_{n-1}a_{n-2}...a_1a_0$ — запись числа, строка цифр,
  • $\ .\ .\ .\ _{2,2}$ — обозначение основания системы кодирования и основания системы счисления,
  • $n$ — количество цифр (знаков) в числе $x_{2,2}$,
  • $k$ — порядковый номер цифры,
  • $a_k$ — цифры числа $x_{2,2} из множества $a={0,1}$, в двоичной системе счисления, основание системы кодирования равно 2,
  • $b=2$ — основание показательной весовой функции, основание системы счисления,
  • $b^k=2^k$ — весовая показательная функция, создающая весовые коэффициенты.

Восьмеричная, шестнадцатеричная

Позиционная целочисленная система счисления с основанием 8 (используются цифры от 0 до 7).

Таблица перевода восьмеричных чисел в двоичные:

08 = 0002
18 = 0012
28 = 0102
38 = 0112
48 = 1002
58 = 1012
68 = 1102
78 = 1112
Для перевода восьмеричного числа в двоичное необходимо заменить каждую цифру восьмеричного числа на триплет двоичных цифр. Например: 25418 = [ 28 | 58 | 48 | 18 ] = [ 0102 | 1012 | 1002 | 0012 ] = 0101011000012

Аналогично, для шестнадцатеричной системы каждая цифра заменяется группой из четырёх двоичных цифр.

Реализация на Python

# Перевод между двоичной и системами с основанием 8 или 16 через группы цифр: O(n) операций
DIGITS = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"


def base_to_binary(text, group_size):
    """Каждая цифра записи (основание 2**group_size) заменяется группой из group_size двоичных цифр."""
    bits = []
    for symbol in text:
        digit = DIGITS.find(symbol)
        if not 0 <= digit < 2 ** group_size:
            raise ValueError(f"цифра {symbol!r} не входит в систему с основанием {2 ** group_size}")
        bits.append(format(digit, f"0{group_size}b"))
    return "".join(bits)


def binary_to_base(bits, group_size):
    """Двоичная запись дополняется нулями слева до кратности group_size и делится на группы по group_size цифр."""
    if not set(bits) <= {"0", "1"}:
        raise ValueError("запись должна состоять из цифр 0 и 1")
    width = (len(bits) + group_size - 1) // group_size * group_size
    padded = bits.zfill(width)
    return "".join(DIGITS[int(padded[i:i + group_size], 2)] for i in range(0, width, group_size))


def main():
    # 3 двоичные цифры на цифру - восьмеричная система, 4 - шестнадцатеричная
    print(base_to_binary("2541", 3))         # 010101100001
    print(binary_to_base("11111101000", 3))  # 3750
    print(base_to_binary("7E8", 4))          # 011111101000
    print(binary_to_base("11111101000", 4))  # 7E8


if __name__ == "__main__":
    main()

// Перевод между двоичной и системами с основанием 8 или 16 через группы цифр: O(n) операций
// group_size - число двоичных цифр в одной цифре: 3 для восьмеричной, 4 для шестнадцатеричной
const DIGITS: &[u8] = b"0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ";

// Каждая цифра записи (основание 2^group_size) заменяется группой из group_size двоичных цифр
pub fn base_to_binary(text: &str, group_size: usize) -> Option<String> {
    let mut bits = String::new();
    for symbol in text.bytes() {
        let digit = DIGITS.iter().position(|&known| known == symbol)?;
        if digit >= 1 << group_size {
            return None;
        }
        bits.push_str(&format!("{digit:0group_size$b}"));
    }
    Some(bits)
}

// Двоичная запись дополняется нулями слева до кратности group_size и делится на группы по group_size цифр
pub fn binary_to_base(bits: &str, group_size: usize) -> Option<String> {
    if !bits.bytes().all(|bit| bit == b'0' || bit == b'1') {
        return None;
    }
    let width = (bits.len() + group_size - 1) / group_size * group_size;
    let padded = format!("{}{bits}", "0".repeat(width - bits.len()));
    let symbols = padded.as_bytes().chunks(group_size).map(|group| {
        let value = group.iter().fold(0, |acc, &bit| acc * 2 + usize::from(bit - b'0'));
        char::from(DIGITS[value])
    });
    Some(symbols.collect())
}

fn main() {
    // 3 двоичные цифры на цифру - восьмеричная система, 4 - шестнадцатеричная
    println!("{}", base_to_binary("2541", 3).unwrap()); // 010101100001
    println!("{}", binary_to_base("11111101000", 3).unwrap()); // 3750
    println!("{}", base_to_binary("7E8", 4).unwrap()); // 011111101000
    println!("{}", binary_to_base("11111101000", 4).unwrap()); // 7E8
}

Реализация на C++

// Перевод между двоичной и системами с основанием 8 или 16 через группы цифр: O(n) операций
// group_size - число двоичных цифр в одной цифре: 3 для восьмеричной, 4 для шестнадцатеричной
#include <cstddef>
#include <iostream>
#include <optional>
#include <string>

const std::string DIGITS = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ";

// Каждая цифра записи (основание 2^group_size) заменяется группой из group_size двоичных цифр
std::optional<std::string> base_to_binary(const std::string& text, std::size_t group_size) {
    std::string bits;
    for (char symbol : text) {
        const std::size_t digit = DIGITS.find(symbol);
        if (digit == std::string::npos || digit >= (std::size_t{1} << group_size)) {
            return std::nullopt;
        }
        // Старшие двоичные цифры группы выводим первыми
        for (std::size_t shift = group_size; shift > 0; --shift) {
            bits += ((digit >> (shift - 1)) & 1U) ? '1' : '0';
        }
    }
    return bits;
}

// Двоичная запись дополняется нулями слева до кратности group_size и делится на группы по group_size цифр
std::optional<std::string> binary_to_base(const std::string& bits, std::size_t group_size) {
    if (bits.find_first_not_of("01") != std::string::npos) {
        return std::nullopt;
    }
    const std::size_t width = (bits.size() + group_size - 1) / group_size * group_size;
    const std::string padded = std::string(width - bits.size(), '0') + bits;
    std::string result;
    for (std::size_t start = 0; start < width; start += group_size) {
        std::size_t value = 0;
        for (std::size_t i = start; i < start + group_size; ++i) {
            value = value * 2 + static_cast<std::size_t>(padded[i] - '0');
        }
        result += DIGITS[value];
    }
    return result;
}

int main() {
    // 3 двоичные цифры на цифру - восьмеричная система, 4 - шестнадцатеричная
    std::cout << base_to_binary("2541", 3).value() << '\n';         // 010101100001
    std::cout << binary_to_base("11111101000", 3).value() << '\n';  // 3750
    std::cout << base_to_binary("7E8", 4).value() << '\n';          // 011111101000
    std::cout << binary_to_base("11111101000", 4).value() << '\n';  // 7E8
    return 0;
}

Перевод целых чисел из 10 системы счисления в любую

Для перевода надо делить "в столбик" число на основание системы счисления. Каждый очередной остаток будет цифрой числа

Вывод числа в произвольной системе счисления:

{$APPTYPE CONSOLE}

uses SysUtils;

var 
  x, b : longint;
  s : string; { Результат преобразования }
begin
  Write('Введите число: '); Readln(x);
  Write('Введите основание системы счисления: '); Readln(b);  
  s := '';
  while x > 0 do begin
    s := IntToStr(x mod b) + s; { Остаток - это очередная цифра. Приписываем её спереди к числу }
    x := x div b; { Делим на основание системы счисления }
  end;
  if s = '' then s := '0';
  writeln('Результат: ',s);
end.

Реализация на Python

# Перевод целого числа в систему с основанием base делением с остатком: O(log n) делений
DIGITS = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"


def to_base(number, base):
    """Возвращает запись неотрицательного числа number цифрами системы с основанием от 2 до 36."""
    if number < 0 or not 2 <= base <= 36:
        raise ValueError("число должно быть неотрицательным, основание от 2 до 36")
    if number == 0:
        return "0"
    digits = []
    while number > 0:
        # Остаток от деления - очередная цифра; первые остатки оказываются младшими разрядами
        number, remainder = divmod(number, base)
        digits.append(DIGITS[remainder])
    return "".join(reversed(digits))


def main():
    print(to_base(2024, 2))
    print(to_base(255, 16))
    print(to_base(12345, 8))
    print(to_base(0, 10))


if __name__ == "__main__":
    main()

// Перевод целого числа в систему с основанием base делением с остатком: O(log n) делений
const DIGITS: &str = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ";

// Возвращает запись числа number цифрами системы с основанием от 2 до 36
pub fn to_base(mut number: u64, base: u32) -> Option<String> {
    if !(2..=36).contains(&base) {
        return None;
    }
    if number == 0 {
        return Some("0".to_string());
    }
    let radix = u64::from(base);
    let mut digits = Vec::new();
    while number > 0 {
        // Остаток от деления - очередная цифра; первые остатки оказываются младшими разрядами
        digits.push(DIGITS.as_bytes()[(number % radix) as usize] as char);
        number /= radix;
    }
    Some(digits.into_iter().rev().collect())
}

fn main() {
    println!("{}", to_base(2024, 2).unwrap());
    println!("{}", to_base(255, 16).unwrap());
    println!("{}", to_base(12345, 8).unwrap());
    println!("{}", to_base(0, 10).unwrap());
}

Перевод целых чисел из 2-й, 8-й, 16-й в 10 сс

Для перевода умножаем каждую последующую цифру на соответствующую степень 2-ки, 8-рки, 16-ти

Для двоичного числа: $x = a_n{\cdot}2^n + ... + a_1{\cdot}2^1 + a_0{\cdot}2^0$

Реализация на Python

# Перевод из системы с основанием base в десятичную: сумма цифр, умноженных на степени base; O(n) для n цифр
DIGITS = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"


def from_base(text, base):
    """Возвращает десятичное значение записи text в системе с основанием base."""
    value = 0
    weight = 1  # base в степени k для разряда k (справа налево)
    for symbol in reversed(text):
        digit = DIGITS.find(symbol)
        if not 0 <= digit < base:
            raise ValueError(f"цифра {symbol!r} не входит в систему с основанием {base}")
        value += digit * weight
        weight *= base
    return value


def main():
    print(from_base("11111101000", 2))
    print(from_base("FF", 16))
    print(from_base("30071", 8))


if __name__ == "__main__":
    main()

Реализация на Rust


// Перевод из системы с основанием base в десятичную: сумма цифр, умноженных на степени base; O(n) для n цифр

// Возвращает десятичное значение записи text в системе с основанием base (от 2 до 36)
pub fn from_base(text: &str, base: u32) -> Option<u64> {
    if !(2..=36).contains(&base) {
        return None;
    }
    let mut value: u64 = 0;
    let mut weight: u64 = 1; // base в степени k для разряда k (справа налево)
    for symbol in text.chars().rev() {
        value += u64::from(symbol.to_digit(base)?) * weight;
        weight *= u64::from(base);
    }
    Some(value)
}

fn main() {
    println!("{}", from_base("11111101000", 2).unwrap());
    println!("{}", from_base("FF", 16).unwrap());
    println!("{}", from_base("30071", 8).unwrap());
}

// Перевод из системы с основанием base в десятичную: сумма цифр, умноженных на степени base; O(n) для n цифр
#include <cstddef>
#include <cstdint>
#include <iostream>
#include <optional>
#include <string>

// Возвращает десятичное значение записи text в системе с основанием base (от 2 до 36)
std::optional<std::uint64_t> from_base(const std::string& text, std::uint64_t base) {
    const std::string digits = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ";
    if (base < 2 || base > 36) {
        return std::nullopt;
    }
    std::uint64_t value = 0;
    std::uint64_t weight = 1;  // base в степени k для разряда k (справа налево)
    for (auto it = text.rbegin(); it != text.rend(); ++it) {
        std::size_t digit = digits.find(*it);
        if (digit == std::string::npos || digit >= base) {
            return std::nullopt;
        }
        value += digit * weight;
        weight *= base;
    }
    return value;
}

int main() {
    std::cout << from_base("11111101000", 2).value() << '\n';
    std::cout << from_base("FF", 16).value() << '\n';
    std::cout << from_base("30071", 8).value() << '\n';
    return 0;
}

# Римская запись жадным алгоритмом: от старших значений к младшим; O(1) при n < 4000 (13 значений)
ROMAN_TABLE = (
    (1000, "M"), (900, "CM"), (500, "D"), (400, "CD"),
    (100, "C"), (90, "XC"), (50, "L"), (40, "XL"),
    (10, "X"), (9, "IX"), (5, "V"), (4, "IV"), (1, "I"),
)


def to_roman(number):
    """Возвращает римскую запись числа от 1 до 3999."""
    if not 1 <= number <= 3999:
        raise ValueError("римская запись возможна для чисел от 1 до 3999")
    result = ""
    for value, symbol in ROMAN_TABLE:
        # Пока число не меньше значения цифры, вычитаем его и дописываем символ

            number -= value
            result += symbol
    return result

// Римская запись жадным алгоритмом: от старших значений к младшим; O(1) при n < 4000 (13 значений)

const ROMAN_TABLE: [(u32, &str); 13] = [
    (1000, "M"), (900, "CM"), (500, "D"), (400, "CD"), (100, "C"), (90, "XC"), (50, "L"),
    (40, "XL"), (10, "X"), (9, "IX"), (5, "V"), (4, "IV"), (1, "I"),
];

// Возвращает римскую запись числа от 1 до 3999
pub fn to_roman(mut number: u32) -> Option<String> {
    if !(1..=3999).contains(&number) {
        return None;
    }
    let mut result = String::new();
    for &(value, symbol) in &ROMAN_TABLE {
        // Пока число не меньше значения цифры, вычитаем его и дописываем символ
        while number >= value {
            number -= value;
            result.push_str(symbol);
        }
    }
    Some(result)
}

fn main() {
    for number in [4, 1994, 2024, 3999] {
        println!("{number} {}", to_roman(number).unwrap());
    }
}

// Римская запись жадным алгоритмом: от старших значений к младшим; O(1) при n < 4000 (13 значений)
#include <iostream>
#include <stdexcept>
#include <string>
#include <utility>
#include <vector>

// Возвращает римскую запись числа от 1 до 3999
std::string to_roman(int number) {
    const std::vector<std::pair<int, std::string>> table = {
        {1000, "M"}, {900, "CM"}, {500, "D"}, {400, "CD"}, {100, "C"}, {90, "XC"}, {50, "L"},
        {40, "XL"}, {10, "X"}, {9, "IX"}, {5, "V"}, {4, "IV"}, {1, "I"}};
    if (number < 1 || number > 3999) {
        throw std::invalid_argument("римская запись возможна для чисел от 1 до 3999");
    }
    std::string result;
    for (const auto& [value, symbol] : table) {
        // Пока число не меньше значения цифры, вычитаем его и дописываем символ
        while (number >= value) {
            number -= value;
            result += symbol;
        }
    }
    return result;
}

int main() {
    for (int number : {4, 1994, 2024, 3999}) {
        std::cout << number << ' ' << to_roman(number) << '\n';
    }
    return 0;
}

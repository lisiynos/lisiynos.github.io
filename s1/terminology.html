Множества

Множество - совокупность объектов (элементов), объединённых по какому-либо признаку. Множество записывают перечислением элементов в фигурных скобках, например $A = \{1, 2, 3\}$, или описанием свойства, например $\{x \mid x \in \mathbb{Z},\ 1 \le x \le 3\}$, которое задаёт то же множество $A$.

Элемент множества - объект, входящий в это множество. Запись $a \in A$ читается «$a$ принадлежит $A$», запись $a \notin A$ - «$a$ не принадлежит $A$». Для $A = \{1, 2, 3\}$ верно $2 \in A$ и $5 \notin A$.

Пустое множество $\varnothing$ - множество, не содержащее ни одного элемента.

Подмножество: запись $B \subseteq A$ означает, что каждый элемент $B$ принадлежит $A$. Например, $\{1, 3\} \subseteq \{1, 2, 3\}$. Пустое множество является подмножеством любого множества.

Объединение $A \cup B$ - множество элементов, принадлежащих хотя бы одному из множеств $A$ и $B$; пересечение $A \cap B$ - элементов, принадлежащих обоим множествам; разность $A \setminus B$ - элементов $A$, не принадлежащих $B$. Для $A = \{1, 2, 3\}$ и $B = \{2, 3, 4\}$ получаем $A \cup B = \{1, 2, 3, 4\}$, $A \cap B = \{2, 3\}$, $A \setminus B = \{1\}$.

Мощность конечного множества $A$ - число его элементов, обозначается $|A|$. Для множеств из предыдущего примера $|A| = |B| = 3$, $|A \cap B| = 2$, $|A \cup B| = 4$, и выполняется равенство $|A \cup B| = |A| + |B| - |A \cap B|$.

Декартово произведение $A \times B$ - множество всех упорядоченных пар $(a, b)$, где $a \in A$ и $b \in B$. Его мощность равна $|A| \cdot |B|$: для $A = \{1, 2\}$ и $B = \{x, y\}$ получаем $A \times B = \{(1, x), (1, y), (2, x), (2, y)\}$, то есть четыре пары.

Основные числовые множества: натуральные $\mathbb{N} = \{1, 2, 3, \dots\}$ (в некоторых книгах к ним относят и $0$), целые $\mathbb{Z}$, рациональные $\mathbb{Q}$ - числа вида $\frac{p}{q}$, где $p \in \mathbb{Z}$, $q \in \mathbb{N}$, и вещественные $\mathbb{R}$. Выполняются включения $\mathbb{N} \subseteq \mathbb{Z} \subseteq \mathbb{Q} \subseteq \mathbb{R}$.

Формулы

Выражение - запись, составленная из чисел, букв (переменных) и знаков операций, например $3x + 2$. Выражение не содержит знака отношения и само по себе не бывает верным или неверным.

Формула - в школьной математике равенство или неравенство, в котором величины записаны буквами, например $S = \pi r^2$ - формула площади круга радиуса $r$. В математической логике формула - правильно построенная запись из логических переменных и связок (см. «Алгебра логики»).

Тождество - равенство, верное при всех допустимых значениях букв, например $(a + b)^2 = a^2 + 2ab + b^2$. Равенство $\frac{x^2 - 1}{x - 1} = x + 1$ является тождеством при $x \ne 1$, так как при $x = 1$ левая часть не имеет смысла.

Уравнение - равенство, которое верно лишь при некоторых значениях неизвестного; такие значения называют корнями уравнения. Например, $x^2 - 5x + 6 = 0$ имеет корни $x = 2$ и $x = 3$, поскольку $x^2 - 5x + 6 = (x - 2)(x - 3)$.

Неравенство - запись вида $A < B$, $A \le B$, $A > B$ или $A \ge B$. Например, $x^2 \ge 0$ верно при всех вещественных $x$.

Область определения формулы - множество значений переменных, при которых формула имеет смысл. Например, для $\frac{1}{x - 1}$ областью определения служат все $x \ne 1$.

Квантор всеобщности $\forall$ читается «для всех», квантор существования $\exists$ - «существует». Запись $\exists x \in \mathbb{R}\ (x^2 = 2)$ означает, что существует вещественное число $x$, для которого $x^2 = 2$.

Знак суммы: $\sum_{k=1}^{n} k = \frac{n(n + 1)}{2}$; при $n = 10$ сумма равна $55$.

Ассемблер (ASM)

Язык программирования низкого уровня максимально приближён к программированию в машинных кодах. В отличие от машинных кодов, в языке низкого уровня каждой команде соответствует не число, а сокращённое название команды (мнемоника - для удобства запоминания). Например, команда ADD – это сокращение от слова ADDITION (сложение). Поэтому использование языка низкого уровня существенно упрощает написание и чтение программ (по сравнению с программированием в машинных кодах).

Язык низкого уровня привязан к конкретному процессору (программы не переносимы с одного процессора на другой), но общие принципы во всех ассемблерах одинаковы.

Среда разработки Emu8086

Emu8086 — учебная среда для программирования на ассемблере процессора Intel 8086. Она объединяет редактор исходного текста, ассемблер, дизассемблер, программный эмулятор (виртуальный ПК) с отладчиком и пошаговые учебные материалы. Программа запускается файлом Emu8086.exe или из меню «Пуск». Описание дано по справке Emu8086, версия 3.07; в более поздних версиях состав и интерфейс могут отличаться.

Программа транслируется и выполняется на эмуляторе по шагам, и во время работы видны значения регистров, флагов и памяти. Эмулятор запускает программу на виртуальном ПК и не даёт ей обращаться к реальному оборудованию, что упрощает отладку.

Программу пишут в редакторе исходного текста или открывают готовый пример: в меню «File» выбирают «Samples», и все примеры подробно прокомментированы. Кнопка [Compile] транслирует программу и спрашивает, куда сохранить скомпилированный файл; кнопка [Emulate] загружает этот файл в эмулятор. Кнопка [Compile and Emulate] (клавиша F5) выполняет оба действия сразу. Кнопка [Single Step] (клавиша F8) выполняет программу по одной команде.

Директива в тексте программы задаёт формат результата трансляции:

  • #MAKE_COM# — файл COM, самый простой формат. Перед кодом пишут директиву ORG 100h; выполнение начинается с первого байта файла.
  • #MAKE_EXE# — файл EXE, не ограниченный по размеру и числу сегментов. Сегмент стека и точку входа задаёт программист.

Есть также форматы #MAKE_BIN# и #MAKE_BOOT#. По справке, файлы COM и EXE поддерживаются DOS и командной строкой Windows.

Среда запускает программы, рассчитанные на DOS. В версии 3.07 MS-DOS в эмуляторе не загружается целиком; вместо него эмулируются отдельные функции DOS и некоторые BIOS-прерывания. Из функций DOS поддерживаются, в частности: INT 20h (выход в операционную систему); INT 21h с функциями 01h (ввод символа с выводом на экран), 02h (вывод символа), 09h (вывод строки по адресу DS:DX; строка заканчивается знаком доллара), 0Ah (ввод строки) и 4Ch (выход в операционную систему).

Синтаксис Emu8086, по справке, совместим с MASM и TASM; собственные директивы, начинающиеся с символа #, другие ассемблеры не понимают.

Пример программы в формате COM, которая выводит строку и завершается. Фрагмент приведён для иллюстрации и не проверялся трансляцией и запуском.

#MAKE_COM#
ORG 100h
MOV DX, OFFSET msg   ; DS:DX = address of the string
MOV AH, 09h          ; DOS function 09h: print the string
INT 21h
MOV AX, 4C00h        ; DOS function 4Ch: exit, return code 0
INT 21h
msg DB 'Hello, world!$'

Арифметические команды

Арифметические команды выполняют сложение, вычитание, умножение и деление целых чисел, которые находятся в регистрах или в памяти; сложение и вычитание могут также брать второе число прямо из команды (непосредственный операнд). В командах сложения и вычитания первый операнд (приёмник) получает результат. После большинства арифметических команд процессор устанавливает или сбрасывает флаги — однобитовые признаки результата, по которым работают условные переходы. Для арифметики важны четыре флага:

  • CF (carry flag) — признак беззнакового переполнения: результат выходит за пределы $0 \le x \le 255$ для байта или $0 \le x \le 65535$ для слова. Например, при сложении $255 + 1$ флаг CF равен 1. При вычитании CF равен 1, если беззнаковое уменьшаемое меньше вычитаемого (заём).
  • ZF (zero flag) — равен 1, если результат равен нулю, иначе 0.
  • SF (sign flag) — равен старшему биту результата: 1, если результат отрицателен при знаковой интерпретации, иначе 0.
  • OF (overflow flag) — признак знакового переполнения: 1, если результат не помещается в знаковый диапазон $-128 \le x \le 127$ для байта или $-32768 \le x \le 32767$ для слова (для MUL правило другое, см. ниже). Например, при сложении $100 + 50$ флаг OF равен 1.

Ниже перечислены команды и флаги, которые они устанавливают. Флаги AF и PF у команд ADD, SUB, INC и DEC тоже устанавливаются по результату, но здесь не рассматриваются.

  • ADD приёмник, источник — приёмник := приёмник + источник. Флаги CF, ZF, SF, OF устанавливаются по результату.
  • SUB приёмник, источник — приёмник := приёмник − источник. Флаги CF, ZF, SF, OF устанавливаются по результату; CF означает заём.
  • INC операнд — операнд := операнд + 1. Флаги ZF, SF, OF устанавливаются по результату; флаг CF не изменяется.
  • DEC операнд — операнд := операнд − 1. Флаги ZF, SF, OF устанавливаются по результату; флаг CF не изменяется.
  • MUL источник — беззнаковое умножение. Для байтового источника AX := AL × источник, для словного DX:AX := AX × источник. Флаги CF и OF равны 0, если старшая половина результата (AH или DX) равна нулю, и равны 1 в противном случае. Флаги SF, ZF, AF, PF не определены.
  • DIV источник — беззнаковое деление. Для байтового источника AL := AX ÷ источник (частное), AH := остаток; для словного AX := (DX:AX) ÷ источник (частное), DX := остаток. Если частное не помещается в AL (или в AX) либо источник равен нулю, процессор формирует исключение деления #DE. Все флаги после DIV не определены.

Для знаковых чисел используются команды IMUL и IDIV.

Пример (синтаксис Emu8086; фрагменты приведены для иллюстрации и не проверялись трансляцией):

MOV AL, 255
ADD AL, 1      ; AL = 0, CF = 1, ZF = 1, SF = 0, OF = 0
MOV AL, 100
ADD AL, 50     ; AL = 150 (96h), CF = 0, ZF = 0, SF = 1, OF = 1
MOV AL, 3
SUB AL, 5      ; AL = 254 (0FEh), CF = 1, ZF = 0, SF = 1, OF = 0
MOV AL, 200
MOV BL, 4
MUL BL         ; AX = 800 (0320h), CF = 1, OF = 1
MOV AX, 203
MOV BL, 4
DIV BL         ; AL = 50 (32h), AH = 3

Источники: справка Emu8086, версия 3.07 (определения флагов — часть 6 учебника «8086 Assembler Tutorial for Beginners»; описания команд ADD, SUB, INC, DEC, MUL, DIV); описания команд в неофициальном справочнике x86: SUB, INC, DEC, MUL, DIV.

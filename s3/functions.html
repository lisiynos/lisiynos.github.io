Функции

Функция — именованный фрагмент программы: она получает данные через параметры, выполняет вычисления и может вернуть результат. В C и C++ определение функции состоит из типа результата, имени, списка параметров в круглых скобках и тела в фигурных скобках. Функция main — точка входа программы.

Параметры по значению и по ссылке

Параметр, объявленный обычным образом, получает копию значения аргумента. Изменения этой копии внутри функции не видны в вызывающей части программы. Параметр-ссылка объявляется со знаком &, например int& x: это другое имя для переменной-аргумента, поэтому изменения внутри функции действуют на исходную переменную. В языке C ссылок нет, и тот же результат получают, передавая адрес переменной через указатель.

Реализация на C++

// Параметры по значению и по ссылке в C++
#include <cstdio>

// Параметр по значению: функция работает с копией аргумента
void add_one_by_value(int x) {
  ++x;
}

// Параметр по ссылке: функция меняет переменную, переданную в аргументе
void add_one_by_reference(int& x) {
  ++x;
}

// Обмен значений двух переменных через ссылки
void swap_by_reference(int& a, int& b) {
  int t = a;
  a = b;
  b = t;
}

int main() {
  int x = 10;
  int y = 20;
  add_one_by_value(x);
  std::printf("после передачи по значению: x = %d\n", x);
  add_one_by_reference(x);
  std::printf("после передачи по ссылке: x = %d\n", x);
  swap_by_reference(x, y);
  std::printf("после обмена: x = %d, y = %d\n", x, y);
  return 0;
}

Реализация на C

/* В C ссылок нет: изменяемый параметр передаётся указателем */
#include <stdio.h>

void add_one_by_value(int x) {
    x++;  /* меняется только локальная копия */
}

void add_one_by_pointer(int *x) {
    (*x)++;  /* меняется переменная, на которую указывает x */
}

void swap_by_pointer(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

int main(void) {
    int x = 10;
    int y = 20;
    add_one_by_value(x);
    printf("после передачи по значению: x = %d\n", x);
    add_one_by_pointer(&x);
    printf("после передачи указателя: x = %d\n", x);
    swap_by_pointer(&x, &y);
    printf("после обмена: x = %d, y = %d\n", x, y);
    return 0;
}

Передача массивов

Массив нельзя передать по значению: при вызове имя массива превращается в указатель на его первый элемент. Параметры int* a и int a[] задают один и тот же указатель, поэтому функция не знает, сколько элементов в массиве, и размер передаётся отдельным параметром. Через указатель функция может менять элементы массива, и изменения видны вызывающей части программы. В C++ массив фиксированного размера можно передать по ссылке, записав тип параметра как int (&a)[5]; тогда размер входит в тип. Вектор std::vector передают по ссылке: он хранит свой размер, и функция может добавлять в него элементы.

Реализация на C++

// Передача массивов в C++: указатель с размером, ссылка на массив фиксированного размера и вектор по ссылке
#include <cstdio>
#include <vector>

// Массив передаётся указателем; размер передаётся отдельным параметром
long long sum_by_pointer(const int* a, int n) {
  long long sum = 0;
  for (int i = 0; i < n; ++i) sum += a[i];
  return sum;
}

// Массив из пяти элементов передаётся по ссылке: размер входит в тип параметра
void fill_squares(int (&a)[5]) {
  for (int i = 0; i < 5; ++i) a[i] = i * i;
}

// Вектор передаётся по ссылке: функция может добавить в него элемент
void push_value(std::vector<int>& v, int value) {
  v.push_back(value);
}

int main() {
  int squares[5];
  fill_squares(squares);
  std::printf("квадраты:");
  for (int i = 0; i < 5; ++i) std::printf(" %d", squares[i]);
  std::printf("\n");
  std::printf("сумма через указатель: %lld\n", sum_by_pointer(squares, 5));
  std::vector<int> values;
  push_value(values, 7);
  push_value(values, 8);
  std::printf("размер вектора: %zu, сумма: %lld\n", values.size(), sum_by_pointer(values.data(), static_cast<int>(values.size())));
  return 0;
}

Рекурсия

Рекурсивная функция вызывает саму себя для других аргументов. У рекурсии есть базовый случай, при котором вызовы прекращаются, и шаг рекурсии, который сводит задачу к той же задаче для меньших аргументов. Если базового случая нет или шаг не приближает к нему, вызовы не заканчиваются и стек вызовов переполняется. Подробнее о стеке вызовов — в уроке о рекурсии.

Факториал

Факториал целого $n \geq 0$ задаётся равенствами $0! = 1$ и $n! = n \cdot (n - 1)!$ при $n \geq 1$. Базовый случай — $0! = 1$, шаг уменьшает $n$ на единицу. Значение $20! = 2432902008176640000$ помещается в 64-битный беззнаковый тип, а $21!$ уже не помещается. Поэтому программа на C++ даёт верный результат только при $n \leq 20$; в Python целые числа произвольной длины, но глубина рекурсии там ограничена.

Числа Фибоначчи

Функция fib повторяет определение $F_n = F_{n-1} + F_{n-2}$ и потому многократно вычисляет одни и те же значения: число её вызовов быстро растёт. Подробный разбор чисел Фибоначчи, оценка числа вызовов и вариант с циклом — в разделе «Рекуррентные отношения».

Наибольший общий делитель

Алгоритм Евклида записывается рекурсивно: $\operatorname{gcd}(a, 0) = a$ и $\operatorname{gcd}(a, b) = \operatorname{gcd}(b, a \bmod b)$ при $b \neq 0$. Остаток $a \bmod b$ меньше $b$, поэтому второй аргумент строго убывает и вызовы заканчиваются. Подробный разбор алгоритма и оценка числа шагов — в уроке о рекурсии.

Реализация на Python

# Рекурсивные функции: факториал, числа Фибоначчи и наибольший общий делитель
def factorial(n):
    """Возвращает n! для целого n >= 0."""
    # Базовый случай: 0! = 1
    if n == 0:
        return 1
    # Шаг рекурсии: n! = n * (n - 1)!
    return n * factorial(n - 1)


def fib(n):
    """Возвращает n-е число Фибоначчи: F(0) = 0, F(1) = 1, F(n) = F(n - 1) + F(n - 2)."""
    # Базовые случаи: F(0) = 0 и F(1) = 1
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)


def gcd(a, b):
    """Возвращает наибольший общий делитель неотрицательных целых a и b."""
    # Базовый случай: остаток стал нулём, значит a — ответ
    if b == 0:
        return a
    return gcd(b, a % b)


def main():
    print(f"0! = {factorial(0)}, 5! = {factorial(5)}, 20! = {factorial(20)}")
    print("Числа Фибоначчи:", *(fib(n) for n in range(11)))
    print(f"НОД(48, 18) = {gcd(48, 18)}")
    print(f"НОД(17, 0) = {gcd(17, 0)}")
    print(f"НОД(12, 35) = {gcd(12, 35)}")


if __name__ == "__main__":
    main()

Реализация на C++

// Рекурсивные функции: факториал, числа Фибоначчи и наибольший общий делитель
#include <cstdio>

// Возвращает n! для n >= 0; верный результат получается только при n <= 20 (21! не помещается в 64 бита)
unsigned long long factorial(unsigned int n) {
  // Базовый случай: 0! = 1
  if (n == 0) return 1;
  // Шаг рекурсии: n! = n * (n - 1)!
  return n * factorial(n - 1);
}

// Возвращает n-е число Фибоначчи: F(0) = 0, F(1) = 1, F(n) = F(n - 1) + F(n - 2)
unsigned long long fib(unsigned int n) {
  // Базовые случаи: F(0) = 0 и F(1) = 1
  if (n < 2) return n;
  return fib(n - 1) + fib(n - 2);
}

// Возвращает наибольший общий делитель неотрицательных целых a и b
unsigned long long gcd(unsigned long long a, unsigned long long b) {
  // Базовый случай: остаток стал нулём, значит a — ответ
  if (b == 0) return a;
  return gcd(b, a % b);
}

int main() {
  std::printf("0! = %llu, 5! = %llu, 20! = %llu\n", factorial(0), factorial(5), factorial(20));
  std::printf("Числа Фибоначчи:");
  for (unsigned int n = 0; n <= 10; ++n) {
    std::printf(" %llu", fib(n));
  }
  std::printf("\n");
  std::printf("НОД(48, 18) = %llu\n", gcd(48, 18));
  std::printf("НОД(17, 0) = %llu\n", gcd(17, 0));
  std::printf("НОД(12, 35) = %llu\n", gcd(12, 35));
  return 0;
}

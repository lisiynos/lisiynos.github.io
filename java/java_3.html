Соглашения по именованию

Регистр букв в именах пакетов, классов, методов, переменных и констант разобран на странице «Типы. Операторы. Объектная модель в Java». Здесь — соглашения для массивов, вложенных классов, исключений и коллекций.

  • Массивы. Скобки пишут после типа элемента: int[] marks. Запись int marks[] тоже компилируется, но соглашения её не рекомендуют: скобки относятся к типу, а не к имени.
  • Массивы и коллекции удобно называть существительным во множественном числе: marks, students; переменную цикла — тем же словом в единственном числе: for (Student student : students).
  • Вложенные и внутренние классы называют так же, как классы верхнего уровня: GradeBook.Student. Компилятор сохраняет такой класс в отдельный файл GradeBook$Student.class. Знак $ разрешён в идентификаторах, но спецификация языка рекомендует применять его только в автоматически сгенерированном коде, поэтому в своих именах его не пишут.
  • Исключения. Имя класса исключения, как правило, заканчивается словом Exception: IllegalArgumentException, IOException; имя подкласса Error — обычно словом Error: OutOfMemoryError, StackOverflowError. Это соглашение, а не правило языка: в самом JDK есть SQLWarning и ThreadDeath. Собственные исключения удобно называть так же.
  • Параметры типа обобщённых классов и методов — одна заглавная буква: T (type), E (element) в коллекциях, K и V (key, value) в словарях Map<K, V>.

Реализация на Java

import java.util.ArrayList;
import java.util.List;

/**
 * Имена массивов, коллекций, вложенных классов и параметров типа
 */
public class GradeBook {
    // Вложенный класс называют так же, как обычный: UpperCamelCase
    static class Student {
        final String name;
        final int[] marks; // скобки массива стоят после типа

        Student(String name, int[] marks) {
            this.name = name;
            this.marks = marks;
        }

        double averageMark() {
            if (marks.length == 0) {
                throw new IllegalArgumentException("У студента " + name + " нет оценок");
            }
            int sum = 0;
            for (int mark : marks) {
                sum += mark;
            }
            return (double) sum / marks.length;
        }
    }

    // Параметр типа: одна заглавная буква
    static <T> T lastOf(List<T> items) {
        return items.get(items.size() - 1);
    }

    public static void main(String[] args) {
        // Коллекция: существительное во множественном числе
        List<Student> students = new ArrayList<>();
        students.add(new Student("Анна", new int[] {5, 4, 5, 4}));
        students.add(new Student("Борис", new int[] {3, 4}));
        students.add(new Student("Вера", new int[0]));

        for (Student student : students) {
            try {
                System.out.println(student.name + ": " + student.averageMark());
            } catch (IllegalArgumentException e) {
                System.out.println(e.getMessage());
            }
        }
        System.out.println("Последний в списке: " + lastOf(students).name);
    }
}

Программа выводит:

Анна: 4.5
Борис: 3.5
У студента Вера нет оценок
Последний в списке: Вера

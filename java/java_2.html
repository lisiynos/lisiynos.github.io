Соглашения по именованию

Компилятор требует, чтобы открытый (public) класс лежал в файле с тем же именем: класс HelloWorld — в файле HelloWorld.java (см. раздел «Работа из командной строки» на странице «ООП. Первое Java приложение»). Остальные соглашения компилятор не проверяет: это договорённость, которой следует стандартная библиотека Java. По виду имени сразу понятно, что оно обозначает: класс, метод, переменную или константу.

  • Пакеты — только строчные буквы: java.util. Имя пакета своего проекта обычно начинают с перевёрнутого доменного имени организации: com.example.shop.
  • Классы, интерфейсы и перечисления — UpperCamelCase: каждое слово с заглавной буквы, без разделителей: HelloWorld, StringBuilder. Класс называют существительным, интерфейс — существительным или прилагательным: List, Comparable, Runnable.
  • Методы — lowerCamelCase: первое слово со строчной буквы, остальные с заглавной. Имя метода обычно глагол: println, toString, getName и setName для чтения и записи поля. Имя метода, который возвращает boolean, часто начинают с is или has: isEmpty, hasNext.
  • Переменные, поля и параметры — тоже lowerCamelCase: studentCount, groupName. Имя из одной буквы допустимо для счётчика цикла (i, j) и временной переменной.
  • Константы (поля static final с неизменяемым значением) и элементы перечислений — заглавные буквы, слова через подчёркивание: Integer.MAX_VALUE, Math.PI, MAX_SIZE, Weekday.MONDAY.

Общие требования к именам (осмысленность, глагол в имени функции) разобраны в лекции «Стиль оформления кода программы». В Java те же имена записывают в lowerCamelCase: getDomainName, а не get_domain_name.

Реализация на Java

/**
 * Соглашения по именованию: класс, поля, методы, константа, перечисление
 */
public class StudentGroup {
    // Константа: заглавные буквы, слова через подчёркивание
    static final int MAX_SIZE = 3;

    // Перечисление названо как класс, его элементы - как константы
    enum Weekday { MONDAY, WEDNESDAY, FRIDAY }

    // Поля: lowerCamelCase
    private final String groupName;
    private int studentCount;

    StudentGroup(String groupName) {
        this.groupName = groupName;
    }

    // Методы: глаголы в lowerCamelCase
    void addStudent() {
        studentCount++;
    }

    boolean isFull() {
        return studentCount == MAX_SIZE;
    }

    String getGroupName() {
        return groupName;
    }

    public static void main(String[] args) {
        StudentGroup group = new StudentGroup("Java-1");
        while (!group.isFull()) {
            group.addStudent();
        }
        System.out.println(group.getGroupName() + ": " + group.studentCount + " из " + MAX_SIZE);
        System.out.println("Первое занятие: " + Weekday.MONDAY);
    }
}

Программа выводит:

Java-1: 3 из 3
Первое занятие: MONDAY
